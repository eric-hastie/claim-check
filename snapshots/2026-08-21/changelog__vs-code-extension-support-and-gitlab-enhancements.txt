 VS Code & GitLab Enhancements 
 Optibot Acadia 2.3.0 — VS Code local review support, improved multi-line GitLab comments, smarter follow-up context, and larger API request handling. 

 Optibot — Acadia 2.3.0

This release introduces new under-the-hood infrastructure changes to support local reviews within VS Code and Cursor. We also made significant improvements to our GitLab integration, as well as numerous under-the-hood enhancements to improve stability and performance.

 Features
 VS Code Extension Support: This release includes the foundational backend support for our upcoming VS Code extension. Soon, you'll be able to get Optibot reviews directly within your editor, making your workflow even more seamless.
 Improvements
 Enhanced GitLab Multi-line Comments: We've significantly improved how Optibot handles multi-line comments in GitLab. Comments on multiple lines of code will now be accurately placed, making reviews clearer and more precise.
 Smarter GitLab Review Context: When you request a follow-up review in GitLab, Optibot will now consider its previous comments, leading to more context-aware and relevant feedback.
 Improved GitLab Pagination: We've fixed a bug that could cause issues with pagination when fetching data from GitLab, ensuring that all your information is retrieved correctly.
 Increased API Request Size: The maximum request size for our API has been increased, allowing you to send larger patches for review.
 Under the Hood Improvements
 More Robust Error Handling: We've implemented a more sophisticated retry mechanism for our AI agents. This makes our system more resilient to transient network issues and temporary service overloads, ensuring that your reviews are completed successfully.
 Dependency Updates: We've updated several dependencies to their latest versions to incorporate the latest security patches and performance improvements.
