 Frequently Asked Questions
 Everything you need to know about Optibot before getting started.

 What is the Optibot Claude Code skill? A skill that runs Optibot directly inside Claude Code. Just say "review this" and Optibot automatically runs a deep, multi-pass review of your code, without ever leaving your Claude workflow.

 How is this different from Claude Code's built-in reviewer? Claude Code reviews code it generated itself — one pass, high noise, and at $15–25 per PR it adds up fast. Optibot takes multiple passes, understands your business logic, and catches 2x more breaking changes. One month of Optibot costs less than a single Claude Code review.

 How do I install it? Paste the GitHub link into Claude Code or just say "claude install optibot." You're up and running in under 2 minutes. https://github.com/Optimal-AI/optibot-skill

 Why does Claude Code's reviewer produce so much noise? Claude Code greps through your entire codebase to gather context, fills up the context window, and burns through the rest with tool calls. The result is a signal-to-noise ratio of around 40/60 — almost half the comments are irrelevant. Optibot is built specifically for reviewing, not generating, so every comment is intentional.

 What can Optibot review inside Claude Code? Uncommitted changes, branches, patch files — all through natural language. Just tell Optibot what you want reviewed and it handles the rest.
