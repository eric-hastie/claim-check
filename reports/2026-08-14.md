## Weakened

**gt-usage-pricing.** Out of date as of **2026-04-30** (Greptile changelog, "Flex Usage
Limits"), https://www.greptile.com/docs/code-review-bot/billing-seats

Still literally true that Greptile is usage-based ($30/seat including 50 credits, $1 per
additional credit), but an org can now cap the dollar spend, with reviews beyond the cap
skipped rather than billed, and $0 disabling overage entirely.

The pitch has to move. At the entry tier the two products are the same trade: $30 for 50
credits against $29 for 50 deep reviews, and Greptile adds a free Starter tier plus 50%
off for pre Series A companies under $2M revenue. Flat-rate wins above roughly 60 reviews
per developer per month, which is exactly the high-velocity, agent-native team the Max
tier is written for. Aim it there.

**sq-no-ai-reasoning.** Weakened as of **SonarQube Server 2026.1**,
https://docs.sonarsource.com/sonarqube-server/2026.1/ai-capabilities/ai-codefix

Detection is still rule and pattern based, so "rules cannot reason" holds. What no
longer holds is "no AI": AI CodeFix generates one-click LLM fix suggestions on
Enterprise and Data Center editions, and AI Code Assurance labels projects containing
AI-generated code and holds them to stricter quality gates with taint analysis.

The second one matters more than the feature. Sonar is selling the same thesis Optibot
sells, that AI-written code needs independent verification, to an installed base that
already has budget and a procurement relationship. That is a harder competitor to
displace than a startup with a better reviewer.
